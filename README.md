# SolarFit Hogar — prototipo del Hito 2

Prototipo independiente creado para la entrega de **Investigación y creación**. Su alcance se limita al modelo anual, la sensibilidad mediante `n′(Y)` y tres simulaciones calibradas: Bogotá, Barranquilla y Quibdó.

No reemplaza ni modifica la aplicación final `solarfit-hogar`.

## Ejecución

```powershell
pnpm install
pnpm check
pnpm dev
```

## Alcance deliberado

- Incluye: entradas esenciales, cálculo continuo, redondeo, viabilidad de techo, cobertura y sensibilidad.
- No incluye: API en vivo, PVWatts, persistencia, importación/exportación ni el conjunto ampliado de casos del Hito 3.
